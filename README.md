# Multi-Lens Thinking

一个用于复杂问题决策的 Codex Skill。  
它通过“多职业视角”帮助你跳出单一思维惯性，把问题看得更全、行动更清晰。

## 这个 Skill 做什么

- 把一个问题拆成可分析的核心陈述（先定义问题，不预设方案）
- 动态生成 3-5 个最相关的职业镜头（而不是死记固定列表）
- 对每个镜头做深度扮演（价值观、指标、约束、恐惧、世界观）
- 综合冲突与共识，输出可执行行动方案

## 什么时候用

适合：
- 复杂决策
- 卡住时找新思路
- 需要平衡多方视角（产品、商业、风险、执行）

不适合：
- 有标准答案的纯技术问题
- 时间极紧、必须立即执行的小决策

## 核心流程（5 步）

1. `DEFINE`：一句话定义问题  
2. `GENERATE`：动态生成镜头  
3. `EMBODY`：深度扮演每个镜头  
4. `SYNTHESIZE`：找收敛、张力、空白、惊喜  
5. `ACTION`：输出策略、验证、指标、风险预案

## 使用方式

在 Codex 中直接触发：

```text
Use $multi-lens-thinking to analyze: 我们的 B2B 产品留存率持续下降，应该先改产品还是先改销售策略？
```

也可以中文触发：

```text
请用 $multi-lens-thinking 从 4 个职业视角分析这个问题，并给出 30 天行动计划。
```

## 预期输出

- 3-5 个镜头的结构化分析
- 关键共识与冲突点
- 一个主策略 + 一个最小验证实验
- 成功指标与失败后的备选方案
